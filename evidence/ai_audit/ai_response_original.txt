Biểu đồ đường dưới đây thể hiện kim ngạch xuất khẩu (export_usd) và nhập khẩu (import_usd) của Việt Nam giai đoạn 2005–2024 được vẽ trực tiếp từ dữ liệu gốc trong file trade_year.csv (quy đổi sang đơn vị tỷ USD).
Code Python (Matplotlib)
import matplotlib.pyplot as plt
import pandas as pd

# Đọc dữ liệu gốc từ file CSV
df = pd.read_csv('trade_year.csv')

# Lọc giai đoạn 2005-2024 và sắp xếp theo năm
df = df[(df['year'] >= 2005) & (df['year'] <= 2024)].sort_values('year')

# Quy đổi đơn vị từ USD sang tỷ USD
export_billion = df['export_usd'] / 1e9
import_billion = df['import_usd'] / 1e9

# Khởi tạo biểu đồ
plt.figure(figsize=(12, 6), dpi=150)

# Vẽ hai đường xuất khẩu và nhập khẩu trên cùng một trục Y
plt.plot(
    df['year'],
    export_billion,
    marker='o',
    linewidth=2.2,
    color='#1f77b4',
    label='Xuất khẩu (export_usd)',
)
plt.plot(
    df['year'],
    import_billion,
    marker='s',
    linewidth=2.2,
    color='#ff7f0e',
    label='Nhập khẩu (import_usd)',
)

# Thiết lập tiêu đề, nhãn trục và chú giải
plt.title(
    'Kim ngạch Xuất khẩu và Nhập khẩu của Việt Nam giai đoạn 2005–2024',
    fontsize=14,
    fontweight='bold',
    pad=15,
)
plt.xlabel('Năm', fontsize=12)
plt.ylabel('Kim ngạch (Tỷ USD)', fontsize=12)

# Hiển thị đầy đủ các năm trên trục X và lưới tọa độ
plt.xticks(df['year'], rotation=45)
plt.ylim(bottom=0)
plt.grid(True, linestyle='--', alpha=0.5)
plt.legend(fontsize=11, loc='upper left')

plt.tight_layout()
plt.savefig('vietnam_trade_2005_2024.png', dpi=300)
plt.show()

Một số điểm đáng chú ý từ dữ liệu
Giai đoạn 2005–2011 (Nhập siêu): Kim ngạch nhập khẩu luôn cao hơn xuất khẩu; năm 2005 xuất khẩu đạt 37,48 tỷ USD và nhập khẩu đạt 39,65 tỷ USD.

Bước ngoặt năm 2012: Xuất khẩu lần đầu vượt nhập khẩu (131,36 tỷ USD so với 124,10 tỷ USD) và duy trì trạng thái xuất siêu liên tục đến năm 2024.

Giai đoạn 2022–2024: Sau nhịp điều chỉnh nhẹ vào năm 2023 (xuất khẩu 437,57 tỷ USD, nhập khẩu 324,49 tỷ USD), cả hai chỉ số đều lập đỉnh mới vào năm 2024 với xuất khẩu đạt 505,20 tỷ USD và nhập khẩu đạt 376,83 tỷ USD.
