# Dữ liệu P03

| Thư mục | Nội dung |
| --- | --- |
| `P03 Baci/` | Script xử lý BACI, dữ liệu lọc, dữ liệu sạch và kết quả kiểm tra. |
| `P03 Survey/scripts/` | Script làm sạch khảo sát (T01), phân ngành hàng và mức giá (T04), ghép và tổng hợp dữ liệu (T05). |
| `P03 Survey/data_raw/` | Khảo sát gốc 398 mẫu và bảng phân loại HS2022 của T02 trong `hs/`. |
| `P03 Survey/data_clean/` | Khảo sát đã làm sạch, ba bảng phân nhóm giá và ba bảng đầu ra của T05. |
| `P03 Survey/notes/` | Ghi chú T01, nhật ký các mục cần kiểm tra và ghi chú phân nhóm giá T04. |
| `notebooks/` | Notebook `01_data.ipynb` để chạy lại T05 và kiểm tra dữ liệu bàn giao (T06). |
| `docs/` | Thẻ dữ liệu, bảng mã người thu, nhật ký làm sạch, biểu đồ chất lượng và hướng dẫn chạy T05/T06. |

Xem [hướng dẫn chạy T05 và T06](docs/task56_update.md) và [mô tả các bảng dữ liệu](docs/data_cards.md).
